# Agent Harness 用户使用指南

> 面向最终用户的操作手册 · v0.7.7

## 快速开始

### 启动服务

```bash
# 方式一：直接启动
pip install -e .
python scripts/init_db.py --reindex
python -m harness.main --port 8000

# 方式二：Docker
docker compose up -d
```

打开浏览器访问 `http://localhost:8000`，看到欢迎页即表示服务就绪。

## 聊天对话

### 发送消息

在底部输入框输入问题，按 **Enter** 发送（Shift+Enter 换行）。

发送后你会看到：

- **思考过程**：Agent 的推理步骤实时展示（Thought → Action → Observation），点击可展开详情
- **回答内容**：以 Markdown 格式渲染的最终回复，支持表格、列表、代码块等
- **统计信息**：耗时、步数、Token 消耗

### 停止生成

回答输出过程中，发送按钮变为 **⏹ 停止**。点击可中断当前请求，已生成的部分会保留。

### 示例提问

| 场景 | 示例 |
|---|---|
| 商品推荐 | 预算3000以内，帮我推荐一款拍照好的手机 |
| 订单查询 | 查一下订单20240601001的状态 |
| 物流跟踪 | SF1234567890 这个快递到哪了 |
| 政策咨询 | 激活过的耳机还能七天无理由退货吗 |
| 售后申请 | 订单20240601003我不想要了，帮我申请退货 |
| 组合计算 | 5000元的手机和3000元的耳机各买一台一共多少钱 |
| 多步任务 | 查一下我的所有订单，然后帮我看看哪个该写评价了 |

### 预算约束

提到预算时，Agent 会记住并在后续推荐中持续遵守：

> 你：预算3000以内买个拍照好的手机
> Agent：为您推荐……
> 你：有什么屏幕小的吗
> Agent：（仍会在 3000 元内推荐，因为预算已被记住）

如需修改预算，直接说新金额即可：「改成5000的吧」。

支持多种表达方式：`预算3000` / `3000块的手机` / `3k以内` / `1万以上的笔记本`。

## 会话管理

侧栏显示所有历史会话。每条会话可以：

- **点击**：切换到该会话，查看完整对话和推理轨迹
- **悬停** → ✏️ 重命名
- **悬停** → 🗑️ 删除
- **多选删除**：点击「多选」进入批量模式 → 勾选要删的会话 → 点「删除所选」
- **全选删除**：点击「全选」→ 所有会话打勾 → 点「删除所选」

顶栏「清空」按钮清空当前会话的全部记录（不可恢复）。

### 后台生成

回答生成过程中，你可以自由地：
- 切换到其他会话浏览
- 新建对话
- 浏览指标面板

顶部出现「⏳ 后台生成中」提示，点击返回该会话查看进度。生成完成后结果自动保留。

## 运营管理面板

点击顶栏「管理」打开运营面板。首次使用需输入管理员 Token（默认 `demo-admin-token`，见 `.env` 的 `ADMIN_TOKEN`）。**该 Token 为演示默认值，部署到生产环境前务必修改，否则任何人都能进入运营面板。**

### 商品库 Tab

| 操作 | 说明 |
|---|---|
| 搜索 | 按名称或编号搜索商品 |
| 类别筛选 | 手机 / 笔记本 / 平板 / 耳机 / 穿戴 / 配件 |
| 状态筛选 | 在售 / 下架 |
| 分页 | 每页 15 条，上一页 / 下一页 |
| 编辑 | 点击「编辑」→ 修改名称/价格/描述/标签/库存/状态 → 保存（自动同步向量库） |
| 上架/下架 | 一键切换；下架后用户无法通过对话检索到 |
| 删除 | 从数据库和向量库中彻底移除 |
| 新增 | 填写信息后提交，自动同步向量库 |
| 重建向量索引 | 以数据库为事实源对账式全量重建 |

### 售后审核 Tab

| 操作 | 说明 |
|---|---|
| 查看 | 全部或按状态筛选售后单 |
| 通过 | 待审核 → 已通过（可填备注） |
| 驳回 | 待审核 → 已拒绝（必填原因） |
| 完成打款 | 已通过 → 已完成（模拟退款） |

### 模型热切换

面板顶部的「模型」区域可在不重启的情况下切换 LLM 模型。输入模型名后点「应用」即可生效，前端徽标自动更新。

支持的供应商（均走 OpenAI v1 兼容协议）：OpenAI / 智谱 / DeepSeek / 通义 / 本地 vLLM 等。

## 指标面板

点击顶栏「指标」查看运行时统计：

- LLM 调用次数与 Token 消耗
- 各工具调用分布（柱状图）
- 最近推理轨迹摘要
- 服务运行时间

## 工具清单

点击顶栏「工具」查看当前 Agent 可用的全部工具及其描述。

## 主题切换

顶栏 ◑ 按钮在深色 / 浅色之间切换。偏好自动保存，刷新不丢失。

## 常见问题

**Q: 为什么有的商品显示「暂无库存」？**
A: 库存为 0 的商品仍会出现在检索结果中但标注售罄。管理员可在后台调整库存数量。

**Q: 为什么有的订单查不了？**
A: 出于安全考虑，只能查询本人名下的订单。如果确为本人的订单但无法查询，请联系人工客服核实身份。

**Q: 怎么批量删除会话？**
A: 点击侧栏「多选」→ 勾选要删的会话 → 点「删除所选」。或点「全选」后一键删除。

**Q: Agent 回答的政策是准确的吗？**
A: 政策类问题强制从结构化政策库检索后回答，未命中时引导转人工而非编造条款。
